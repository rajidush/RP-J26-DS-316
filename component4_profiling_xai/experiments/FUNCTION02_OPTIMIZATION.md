# Function 02 optimization protocol

The seed-42 test and seed-20261020 holdout are consumed. Fit preprocessing, feature filtering and novelty estimators on covered normal seed-42 training rows only. Use covered rows from the immediately following original validation interval for feature/window, hyperparameter, mixing-weight, daily-threshold and temporal selection. Reconstruct prior-day inputs from raw daily columns without consuming stored baseline columns, same-day flags, episode IDs, persona or labels. Replay chronological histories, including earlier observed anomalies, with no oracle exclusion. Fix the candidate grids in code before the new cohort is opened.

For the new test, use exactly seed **2026112607** of the existing generator. Generate it only after the validation lock exists. Evaluate its final 34 dates, with the preceding 56 dates available only as unlabeled history. Seed-dependent child profiles and events are new, while the generation procedure, local dates, scenario definitions, monitoring assumptions and child-ID namespace are shared. Never join children across cohorts. Use the saved lock and hash the fresh daily and episode CSVs. Replaying a completed run cannot provide fresh validation evidence, and this cohort is consumed after the first evaluation.

Use the same eligible dates for comparisons. Select a strict score cutoff by maximum validation F1, then fewer false positives, then higher cutoff. Choose a representative for each design by validation F1, FPR, average precision and stable candidate identifier. The global, full personalized, selected personalized and hybrid representatives enter primary selection. Source-only and sensitivity variants are reported as ablations. No test-driven model, threshold, or label changes. Report average precision, confusion matrices and paired child-bootstrap F1/FPR intervals against the optimized global comparator. Temporal candidates maximize validation episode detection minus five times the false-change rate. Count detection only when a new alert falls on an observed labeled episode day, with delay from planned onset. No alerts are graded as clinical outcomes.

Screen, language, calendar and associated derived history are grouped for SHAP and LIME. Evaluate on a deterministic sample of scored rejections and acceptances from the fresh cohort using independent resamples of normal training donors. Report additive error, local surrogate fidelity, sign/rank stability, and signed score drops compared with other groups. The evaluation is synthetic and research-only. It does not replace the deployed artifacts.
